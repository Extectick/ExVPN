# ExVPN

Открытый VPN-клиент с общей кодовой базой Flutter для Android, Windows, Linux и iOS. Первый выпуск ориентирован на Android 11+ и Windows 10/11 x64; VPN-ядро — Xray через собственный адаптер.

**Статус: разработка, технический прототип.** Наличие исходников или успешная сборка не означает, что системный VPN, исключения приложений и защита от утечек уже проверены. Подтверждённые результаты и оставшиеся задачи находятся в [чеклисте](docs/CHECKLIST.md).

## Возможности, запланированные для v1

- Подписки разных провайдеров: HTTPS, текст, QR; обычные и Base64-списки, поддерживаемые профили Xray JSON.
- VLESS/REALITY, XHTTP, VMess, Trojan, Shadowsocks и Hysteria2.
- Исключения приложений внутри TUN и kill switch с явным отображением системных ограничений.
- Тёмная и светлая темы, минималистичная белка, большая кнопка подключения и список серверов.
- Версии приложения и ядра, OTA подписок/данных и подписанные исправления Dart через Shorebird.

Нативное ядро и изменения разрешений обновляются обычным подписанным пакетом приложения. Linux и iOS входят в последующие этапы. Регистрация, платежи и продажа VPN-подписок не входят в v1.

## Порядок разработки

1. Проверить текущее состояние в `docs/CHECKLIST.md` и взять ближайшую задачу с выполненными зависимостями.
2. Завершить системные испытания E1. Пользователь разрешил реализацию выбранного интерфейса параллельно E1; макеты и сборка E2 не подтверждают работоспособность VPN.
3. Проверить результат по критерию задачи; для сетевых возможностей использовать реальное туннельное HTTPS-соединение.
4. Отметить задачу выполненной только вместе с датой, результатом проверки и commit/PR. Публиковать обезличенные доказательства.

Реальные ссылки подписок, ключи, сертификаты подписи и необезличенные журналы не хранятся в Git. Для локальных приватных входных данных предназначен игнорируемый каталог `.private/`.

## Нативная реализация

Android содержит Kotlin `VpnService`, Go/JNI Xray и общий Flutter bridge. Windows содержит Go-службу, TUN/WFP, проверяемый named-pipe IPC и Flutter C++ adapter. Интерфейс вызывает системный модуль; успешное принятие команды не превращается в `connected`. Состояния и защита отображаются по сообщениям native backend.

Инструкции и границы проверенного результата: [Android](native/android/README.md), [Windows](native/windows/README.md). E1 остаётся открытым до реального трафика, исключений и аварийных проверок. Windows требует полный комплект Visual Studio C++/Windows SDK. Browser preview проверяет интерфейс, системный VPN в браузере не запускается.
