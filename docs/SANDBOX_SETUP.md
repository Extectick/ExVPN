# Windows Sandbox: результат подготовки стенда

Проверено 2026-10-16 после второй перезагрузки владельцем. **Sandbox работает**;
в чистом госте прошли установка службы ExVPN, проверка прав, recovery/restart
и удаление. Windows TUN/WFP-приёмка ещё не выполнена.
Рабочий ПК не используется вместо изолированного сетевого стенда.

## Выполненные действия

1. С разрешения владельца запущено включение
   `Containers-DisposableClientVM` с `-All -NoRestart`.
   Результат: `0x800F0831`; CBS сообщил об отсутствующих манифестах компонентов.
2. По отдельному разрешению владельца выполнен штатный
   `DISM /Online /Cleanup-Image /RestoreHealth /NoRestart` через Windows Update.
   Запуск 16:21, окончание 16:59 по местному времени.
   Результат: **`0x800F0915` — файлы для восстановления не найдены**.
   DISM сообщил `Reboot required=no`. Компьютер не перезагружался.

Скрипты находятся в `scripts/qa/enable-windows-sandbox.ps1` и
`scripts/qa/repair-windows-component-store.ps1`. Полные DISM/CBS журналы остаются
локально в `artifacts/windows-sandbox-setup` и системном каталоге журналов;
они не публикуются. Код ошибки не доказывает конкретную сетевую причину.

## Подготовлено штатное восстановление

2026-10-16 владелец разрешил **подготовить** восстановление с сохранением
приложений и файлов. В реальном окне «Система → Восстановление» подтверждена
доступность «Устранение неполадок с помощью Центра обновления Windows».
Открыт завершающий диалог перед запуском. Он сообщает о восстановлении
компонентов и системных файлов с сохранением приложений, документов и параметров.
Флажок автоматической перезагрузки через 15 минут **снят**.

Позднее владелец разрешил запуск без перезагрузки. До подтверждённого нажатия
**OK** управление было прервано физической клавишей Escape. Запуск восстановления
через автоматизацию поэтому не подтверждён. Сам диалог не доказывает, что
Windows Update нашёл подходящий пакет или успешно завершил восстановление.
Снимок только диалога сохранён локально в
`artifacts/windows-sandbox-setup/recovery-confirmation.png`; экран с данными
учётной записи не публикуется.

## Проверка после перезагрузки владельцем

Владелец сообщил о перезапуске. Текущая Windows: Professional 25H2,
**26200.9711** вместо 26200.5670; `LastBootUpTime` — 2026-10-16 20:00 по местному
времени. Номер сборки сам по себе не подтверждает полное исправление CBS.

Sandbox оставался выключен (`Win32_OptionalFeature.InstallState=2`). По ранее
данному разрешению повторно выполнен `enable-windows-sandbox.ps1` с
`-All -NoRestart`. Результат **успешный**: `featureState=Enabled`,
`restartNeeded=true`, `noRestart=true`; CIM подтвердил `InstallState=1`.
Локальное доказательство:
`artifacts/windows-sandbox-setup/enable-after-reboot-20261016.json`.
Прежняя ошибка 0x800F0831 при этом запуске не повторилась.

На этом шаге требовалась отдельно согласованная перезагрузка; `.wsb` ещё не
запускался. ExVPNService на хосте отсутствовал, маршруты/DNS/WFP не менялись.

Владелец затем прямо поручил «Перезагружай комп». Перед отправкой команды
состояние работы сохранено; DISM/установщик/Sandbox не выполнялись. Команда
`shutdown /r /t 0` без принудительного закрытия приложений принята. Владелец
подтвердил перезапуск; новое `LastBootUpTime` — **2026-10-16 20:22:44 +07**.
Компонент включён (`InstallState=1`), установлен Sandbox **0.8.107.0**.

## Первый запуск и исправления ExVPN

Первый гостевой запуск обнаружил ошибку старта службы: WFP вернул
`0xffffffff80320003`, а обработчик не нормализовал результат Win32 `DWORD`.
Отсутствующий фильтр ошибочно считался неисправностью. Исправлено сравнение
младших 32 бит; регрессионные Go tests прошли.

Второй запуск подтвердил установку и работающую LocalSystem-службу, но проверка
ACL ожидала буквальный `GA`. SCM раскрывает его в `SERVICE_ALL_ACCESS`.
Добавлена проверка точных прав SYSTEM/Administrators/Interactive с отказом при
лишних principals, write/start/stop правах Interactive, deny/inherited ACE.
Проверка применяется также самим установщиком; PS5.1 tests прошли.

Третий чистый запуск полностью прошёл 7 шагов install/ACL/recovery/restart/uninstall.
Снимки маршрутов/DNS гостя совпали. Пакет SHA-256
`ce628f2b86d589d8d8e8ed20c98f42963cfdaa49433ca4e31c241775b9e36568`,
подробности и [сводка](evidence/windows-sandbox-installer-smoke.json)
в [WINDOWS_VALIDATION.md](WINDOWS_VALIDATION.md).
Все системные действия ExVPN выполнялись внутри Sandbox; host ExVPNService
по-прежнему отсутствует. Исходники: [b2f4e42](https://github.com/Extectick/ExVPN/commit/b2f4e427075af5f5592904f0f6fdbdc82755af54).

## Альтернативный источник восстановления

Нужен совместимый официальный источник восстановления Windows: WIM/образ с
нужными компонентами, языками и уровнем обновлений. Установленная система
сообщает Professional, 25H2, build `26200.5670`, x64; исходный результат
инвентаризации также определяет её как Insider Preview. Монтированных
установочных дисков и ISO в стандартной папке Downloads на момент проверки нет.
Нельзя считать произвольный Windows ISO совместимым только по названию «Windows 11».

После проверки подходящего источника можно подготовить ограниченный запуск
DISM `/Source` и затем повторить включение Sandbox с запретом перезагрузки.
Этот вариант больше не нужен для повторения включения Sandbox: после
перезагрузки оно прошло успешно. Согласие на восстановление без перезагрузки
не разрешает последующие перезапуски автоматически.

Microsoft описывает требования к уровню обновлений и языковым компонентам
[источника восстановления](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/configure-a-windows-repair-source?view=windows-11).
Отдельная функция
[переустановки текущей версии через Windows Update](https://support.microsoft.com/en-us/windows/deployment/install-upgrade/fix-issues-by-reinstalling-the-current-version-of-windows)
сохраняет приложения, файлы и настройки, но требует перезагрузки для завершения;
её наличие на этом ПК подтверждено; результат её выполнения отдельно не доказан.

## Границы проверки ExVPN

Установка/права службы, recovery/restart и удаление проверены при выключенном
сетевом режиме. TUN, persistent WFP, DNS/IPv6, исключения приложений, падения,
upgrade/rollback и удаление после активного VPN остаются открытыми в E1/E5/E7.
Сборка Windows UI и тесты без привилегий этих проверок не заменяют.
Актуальный пакет и снимки UI перечислены в
[WINDOWS_VALIDATION.md](WINDOWS_VALIDATION.md).
