# Android TV / Google TV

Целевая версия — **Android 11+ (API30+)**, по решению пользователя от 2026-10-21.
Это адаптация выбранного ExVPN UI; она не меняет VPN-политику и не закрывает E1.

## Представление

Android сообщает TV через `UI_MODE_TYPE_TELEVISION`, `FEATURE_TELEVISION` или
`FEATURE_LEANBACK` по отдельному каналу `exvpn/presentation`. Ширина экрана,
ландшафтный телефон и планшет сами по себе TV не включают. При отсутствии канала
остаётся обычное представление; Windows и мобильный Android сохраняют свои режимы.

TV-экран использует логическое полотно960×540 с пропорциональным масштабированием
и безопасными отступами48 по горизонтали/26 по вертикали. Слева — кнопка подключения
и выбранный сервер, справа — прокручиваемые подписки с закреплёнными действиями.
Настройки открываются в центре; подстраницы ограничены по ширине. Жесты снизу и
переключатели оконных формфакторов/Windows PROXY на телевизоре не нужны.

Текст увеличен минимум до1,2; выделение фокуса отличается от выбранного сервера.
Новые зависимости, VPN-разрешения и сторонние дизайн-ресурсы не добавлены.

## Пульт

| Клавиша | Действие |
|---|---|
| Стрелки | Перемещение фокуса; список прокручивается за ним |
| OK / D-pad center / Enter / Gamepad A | Однократное действие выбранного элемента |
| Удержание OK | Не повторяет подключение/отключение |
| Back | Системная клавиатура → окно/подстраница → главный экран |
| Gamepad B / Escape | Возврат в приложении; не останавливает VPN и не завершает процесс |
| Вверх/вниз в поле ввода | Переход к другому элементу после закрытия клавиатуры |
| Влево/вправо в поле ввода | Редактирование текста |

В сегментных переключателях стрелка только переносит фокус; значение применяется
по OK. Так навигация по режимам маршрутизации не меняет политику случайно.
OK в поле ввода повторно вызывает штатную TV-клавиатуру. Первоначальный фокус —
кнопка подключения, в настройках и форме добавления — крестик.

Manifest объявляет необязательный Leanback и необязательный touchscreen,
LEANBACK_LAUNCHER и banner. В списке исключений объединяются обычные и Leanback
launcher-приложения; дубликаты исключены, прежняя проверка shared UID сохранена.
Banner использует существующую белку и Inter/OFL; вектор надписи воспроизводится
`scripts/design/generate-tv-banner.ps1`.

## Проверка и запуск

Быстрый макет: `scripts/design/preview.ps1 -Port8130`, затем
`http://127.0.0.1:8130/?tv=1&lang=ru&theme=dark&update=none`.
Это синтетический UI, а не подтверждение VPN-трафика.

Android debug: `scripts/bootstrap/build-android-debug.ps1 -Demo -RunUnitTests`.
Для изолированной UI-проверки создан ExVPN_TV_API36, tv_1080p, Android TV API36,
serial `emulator-5592`; остальные стенды не использовались. Все действия выполнены
через `adb shell input keyevent`, без Computer Use, tap и swipe.

2026-10-21, исходники `728f6f6cc9e75e6af41b1477dc96ee58c2cebbc9`:
финальный Full12/12 PASS за259,29с,500 app tests (9 TV), analyzer clean,
source fingerprint unchanged; Android JVM77 PASS,0 skipped. Первый Full нашёл
устаревший поиск строки по внутреннему InkWell; тест теперь находит публичный key,
сохраняя прежнюю проверку48–52px на мобильном экране. APK после изменения стартового
фокуса проверен отдельно; повторных JVM/native VPN-испытаний не было.
Web debug-server исчерпал память при параллельной подготовке; TV-эмулятор остановлен
после QA, предпросмотр перезапущен отдельно. Это отказ инструмента разработки,
а не наблюдавшееся падение Android-приложения.

Физический телевизор/пульт, Android TV11 runtime, VPN permission/реальный TUN,
sleep/resume, OTA и производительность на приставках ещё не приняты.
Эмулятор API36 и widget-проверки720p/1080p/4K не заменяют эти критерии.
TV-адаптация опубликована в [0.1.17+39 Preview](https://github.com/Extectick/ExVPN/releases/tag/v0.1.17),
source `b6d449a0545024f3931976f1510ce734b0cc56dc`, UI12. Manifest/Kotlin/banner
потребовали новой полной базы; совместимые дальнейшие изменения Dart/UI идут её
подписанными патчами. Пакет содержит arm64-v8a и x86_64; 32-битные приставки этой
сборкой не поддерживаются. На момент первоначальной публикации точный release
APK39 не устанавливался для повторного runtime-прогона; прежние TV demo-доказательства
сохранены отдельно.
Опубликованные `v0.1.16` и0.1.16+38 не менялись.

## Точный release APK и OTA, 2026-10-22

На собственном TV API36 установлен опубликованный APK39; его SHA совпал с
принятым `69f81d2a…923f9fd`. Автоматический TV-макет и настройки проверены
клавишами пульта. Подписанный patch1/UI13 скачался, движок проверил RSA,
приложение само перезапустилось; диагностика показала current1/next1,
restartRequired=false. Сон/возврат проверен только без VPN.

Один холодный запуск показал телефонный portrait-макет; повторный вернул TV.
Нативные uiMode/leanback признаки при этом остаются TV. Скрытый timeout/channel
exception в старом release не доступен диагностике, поэтому точная причина
не объявляется установленной. `06c983c` повторяет transient hint-запрос до трёх
раз и сохраняет немедленный false для телефона.509 app tests/analyzer PASS.
Actions39731667194 выпустил только подписанный AOT patch2/UI14, каталог16;
полные пакеты и Windows не менялись.

Применение patch2 пока не подтверждено: обычная сеть эмулятора не проверила feed,
а запуск с HTTP proxy отклонила автоматическая approval review без причины.
Proxy не включался обходным способом. TLS/подписи не ослаблялись. Физический TV,
API30, TV permission/TUN, подключённый lifecycle и rollback остаются открытыми.
