# Закрытие Windows TUN: +17

2026-10-17. Подготовлен patch `exvpn.5` ([код d9444db](https://github.com/Extectick/ExVPN/commit/d9444db)); системная приёмка нового пакета ещё
не выполнена. Общие E1/E5 остаются открытыми.

В `exvpn.4` `WindowsTun.ReadPacket` возвращал gVisor-пакет с native
`ReleaseReceivePacket` в отложенном `OnRelease`. `Close` мог уже вызвать
`WintunEndSession`, когда удержанный пакет позднее освобождался. Детерминированный
тест настоящего `ReadPacket → Close → DecRef` с memory-only сессией воспроизвёл
`ReleaseAfterEnd=true`. Адаптер, маршруты, DNS и firewall хоста не создавались.

Это подтверждённая ошибка исходников. Её связь с неожиданным завершением
установленной +16 SCM-службы пока не доказана: в том прогоне отсутствовали
настоящий process exit code и стек.
[Наблюдение +16](evidence/windows-shorebird16-service-exit.json).

Исправление ограничено Windows:

- После уже существующего копирования данных в gVisor native-пакет возвращается
  Wintun немедленно. Удержанный gVisor-пакет больше не обращается к сессии.
- Сессия учитывает начатые Receive/Release, Allocate/Send и event Wait.
  Закрытие запрещает новые операции и будит ожидание отдельным stop event.
- `End` и закрытие handles происходят только после завершения этих операций.
  Повторные Close получают единый результат.
- При отказе wake или превышении пяти секунд ожидания сохраняются native
  handles и возвращается ошибка; успешное закрытие не имитируется.

Девять Windows-тестов проверяют удержанный пакет, порядок native-операций,
ошибки wake/drain, конкурентные Close/Read/Write, независимые сессии и настоящий
Windows event. Исходный RED сохранён; исправление прошло race ×10, пять
существующих lifecycle packages и vet. Независимое ревью не выявило замечаний.
Это проверка исходников, а не установленного SCM/Wintun-пакета.
[Доказательства и точные хеши](evidence/windows-tun-lifetime-build17.json).

Изменение native-кода требует нового APK/Windows-пакета; Dart OTA не используется.
До отдельного runtime-прогона пункт **EXVPN-E5-006** остаётся открытым.
