# ExVPN 0.1.1

Дата: 2026-10-18. Версия исходников: **0.1.1+22**, тег: **v0.1.1**.
Исходники: [5b41a1c](https://github.com/Extectick/ExVPN/commit/5b41a1c070aa1d19675d9af3aabb1939a097fe98).

Изменения относительно опубликованного 0.1.0 Demo:

- Три формата Windows, масштабирование с сохранением пропорций, собственная
  рамка и унифицированные элементы управления.
- Тёмная, светлая и настраиваемая тема, локальные флаги, языки интерфейса
  с системным выбором по умолчанию.
- Обновление подписок без подтверждений, локальные ошибки групп, массовая
  проверка задержки и цветовые диапазоны.
- Переключение серверов и режимов VPN/системный PROXY; управление proxy lease.
- Верхняя полоса обновления, отдельный проверяющий Windows helper,
  сохранение данных перед перезапуском и атомарный отказ автоматической
  установки при активном соединении.
- Отдельный автономный набор проверки updater; связанные проверки протокола,
  подписей, кеша, жизненного цикла UI и установщика.

## Границы версии

Тег фиксирует исходники; он не публикует бинарники и не объявляет стабильную
VPN-приёмку. Подписанный feed, полный цикл автообновления, Windows publisher
signing, физический Android и остальные открытые пункты E1/E6/E7 не закрыты.
Существующий workflow 0.1.0 Demo сохраняется как отдельная историческая доставка.

Последняя установленная и проверенная вручную Windows-сборка — **0.1.0+21**:
[доказательства](evidence/windows-app-updater-build21.json). Смена версии
исходников не заменяет её установленными бинарниками 0.1.1. Windows/APK для
0.1.1 в этом задании не пересобираются и не устанавливаются.

Полный автономный прогон для 0.1.1+22: **12/12 PASS за 85,46 с**, включая
**284 теста приложения**; исходники во время проверки не менялись. Проверены
новые pins updater и синхронность pubspec/build identity. Исправлена единственная
устаревшая UI-проверка версии 0.1.0: она проверяет текущую объявленную версию.
[Full](evidence/fast-validation-v0.1.1.json), [подготовка тега](evidence/version-v0.1.1.json).

В проверяемых изменениях не обнаружены запрещённые выходные файлы, приватный
seed обновлений, ключи или URL предоставленных подписок с токенами. Новые
изображения содержат демонстрационные данные. SDK, бинарники, кеши и `.private/`
остаются вне Git.
