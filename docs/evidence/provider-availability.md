# Доступность приватной тестовой подписки

Проверка 2026-10-16 с Windows-машины разработки. Адрес подписки, домен провайдера,
токен и ответ не публикуются. Использован исходный HTTPS-адрес пользователя,
без перенаправлений и без отключения проверки сертификата. Ограничения:
connect timeout 10 секунд, весь запрос 20 секунд, тело максимум 2 МиБ.

| Время UTC | Результат | Тело |
|---|---|---|
| 09:38:54 | curl exit 28, HTTP 000 | 0 байтов |
| 09:40:21 | curl exit 28, HTTP 000 | 0 байтов |

Во второй попытке DNS занял 0.017555 с; TCP-соединение и TLS-handshake не были
установлены, общий срок 10.011175 с. Это воспроизводимый сетевой тайм-аут с этой
машины до получения HTTP, а не ошибка формата подписки и не доказательство
неисправности сервера. Причина на стороне сети/доступа не установлена.

На этапе планирования также наблюдался timeout. Импорт этой подписки и реальные
профили провайдера не подтверждены. Положительные Android-проверки используют
отдельный синтетический стенд и не подменяют эту проверку.

Дополнение 2026-10-17: повтор исходного адреса с хоста снова завершился timeout
(обычный HTTPS и прямой IPv4). Пользователь затем предоставил другую подписку.
Она загрузилась после обработки HWID challenge: 32 VLESS-записи, 26 принимаются
моделью ExVPN +7, шесть отклоняются. Положительный реальный HTTPS с другим внешним
IPv4 подтверждён для XHTTP/REALITY на Android emulator и Windows Sandbox.
[Полный обезличенный отчёт](../PROVIDER_COMPATIBILITY.md). Исходная недоступная
подписка и новая доступная не считаются одним проверенным источником.
