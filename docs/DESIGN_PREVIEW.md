## Название, буфер и QR, 2026-10-19

Исходники `96444e3`, браузер открыт на проверенном minimal/light.

Название теперь постоянное поле с иконкой над вкладками. При открытии формы
корректная HTTPS-ссылка из буфера подставляется автоматически; остальные данные
буфера не копируются. После паузы ввода загружаются ограниченные метаданные имени.
Ручной ввод не затирается, запоздалый ответ для прежней ссылки не применяется;
автоматическое имя остаётся автоматическим после добавления. Изменение выделения
текста не запускает повторную загрузку. До подтверждения подписка не добавляется.

QR показывает только иконки изображения и камеры. Изображение открывает выбор
«Выбрать файл / Из буфера обмена». Web читает PNG/JPEG из Clipboard API; браузер
может потребовать разрешение. Native prototype читает локальный путь PNG/JPEG
из text clipboard, а не бинарное изображение Windows/Android. Live-сканер камеры
реализован только для браузера: getUserMedia, ограниченные кадры и существующий
ZXing; потоки останавливаются при закрытии или успешном чтении. Реальная камера
на устройстве не проверена, native camera пока недоступна.

Для безопасного воспроизведения автозаполнения в изолированном design entry point
есть синтетический адрес `https://demo.exvpn.invalid/subscription`, возвращающий
«ExVPN Demo». Он не существует в production loader. Другие адреса используют
обычный HTTPS-loader и ограничения CORS. Снимки содержат только синтетические
данные: `design/screenshots/import-autofill/`. Три focused autofill tests и
targeted analyzer PASS; APK/EXE, Full, установку и CI не запускали.

## Компактная вложенность, 2026-10-18

Текущий общий UI использует выбранное пользователем простое дерево: одна линия,
короткие прямые ветки без точек, отступ дочерних строк 24 px. Темы, локальные

визуальные состояния, без VPN и изменений сети. `refreshError=1` сохраняет старый
список и показывает только значок ошибки у подписки; полосы «Повторить» нет.
Обычный клиент использует те же виджеты, но настоящее состояние нативного bridge.

## Последний web-дизайн: обновление и подписки

Открыть `http://127.0.0.1:8127/?desktop=1&layout=medium&lang=ru&theme=light&state=connected&refreshError=1`.
Полоса «Доступно обновление» начинается у верхнего края и занимает 24 px по всей
ширине. Нажатие заменяет её текст/иконку на progress, затем показывает restart
и пересоздаёт UI с макетной версией 0.1.1/build21; размеры canvas не меняются.
Нет HTTP-загрузки обновления, установщика или настоящего OS restart. Для повтора
перезагрузить страницу; `update=none` скрывает полосу в исходном состоянии.

Нажатие обновления подписок при `refreshError=1` показывает ошибку у Основной
подписки, её значок «!» и повтор. В общие сообщения приложения эта ошибка не
попадает. На «!» открывается короткая причина, старые подключения сохранены.
Без `refreshError=1` refresh имитирует успех. Settings: Тёмная / Светлая /
Я дизайнер; поле языка содержит «Русский» или другой текущий endonym.
Null locale продолжает следовать системе до ручного выбора.

Этот цикл не меняет установленную Windows +20 и не создаёт пакеты.

## Быстрый браузерный просмотр

Из корня проекта:

```powershell
pwsh -NoProfile -File scripts/design/preview.ps1
```

Открыть <http://127.0.0.1:8127/?desktop=1&layout=medium>.
Сервер использует закреплённый Flutter и исходники самого интерфейса.
Первый запуск компилирует только браузерный debug-предпросмотр; последующие
изменения применяются клавишей `r` в его терминале, `R` перезапускает макет.
Установщик и APK не создаются. `q` останавливает просмотр.

Отдельная точка входа — `apps/exvpn/lib/design_preview.dart`; `main.dart` её
не импортирует. Данные синтетические, хранилище и native VPN bridge не используются.
Нажатие большой кнопки показывает только анимацию, таймер и макетные счётчики.
Внешняя подпись «Предпросмотр Windows» и ползунок масштаба относятся к стенду,
а не к приложению. Настоящие подписки для согласования дизайна не нужны.

## Форматы

| Режим | Логический размер содержимого | Состав |
|---|---|---|
| Минимальный | 400 × 440 | Шапка, кнопка, выбранное/активное подключение снизу |
| Средний | 440 × 760 | Шапка, кнопка, прокручиваемые группы подключений |
| Большой | 1040 × 680 | Шапка, кнопка и сведения слева, список справа |

Три иконки по центру шапки переключают режим и размер окна стенда.
Ползунок под макетом меняет общий масштаб, сохраняя соотношение сторон,
размеры текста относительно элементов и расположение контролов.
Параметры URL `layout=minimal|medium|large` выбирают начальный режим;
`state=connected` сразу показывает демонстрационный таймер.

Отступы содержимого: слева/справа 20, сверху 12 логических пикселей.
Таймер расположен внутри круга; подписи действия и состояния под ним удалены.
Отдельного названия выбранного узла в среднем режиме нет. В минимальном
оно находится в нижней строке, в большом — в панели сведений.
Значок «!» перед количеством подключений открывает замечания подписки.

## Обновление подписок, задержка и состояние кнопки

Кнопка обновления запускает все подписки с URL без выбора и диалогов,
до трёх загрузок одновременно. Ручные списки без URL пропускаются.
Последний рабочий список и неподтверждённые частичные обновления сохраняются
по прежней политике. Ошибки показываются сверху кратко, с названием подписки;
несколько ошибок идут по очереди, каждую можно закрыть.

Слева от обновления добавлена проверка пинга всех узлов. Визуальные пороги:
до 100 мс — зелёный, 101–250 мс — жёлтый, свыше 250 мс — красный.
В макете значения синтетические: 42/168/342 мс показывают три цвета.
В обычном приложении подготовлен TCP endpoint probe, включающий DNS и handshake,
с дедлайном 3 секунды и максимум четырьмя фактическими DNS/connect operations.
Неподдерживаемые UDP-only варианты, включая Hysteria2, показывают нейтральное «—».
Эта измерительная часть пока не выполнялась на реальной сети и не подтверждает VPN.

По последнему уточнению цвет и фактура диска сохраняются исходными также
в отключённом состоянии. Символ и индикатор — Space Gray `#737980`.
Наведение не включает свет. При отключении свечение и волна
снимаются немедленно; янтарная подсветка остаётся только у active/connecting.

Для просмотра ошибки в симуляторе добавьте `refreshError=1` к URL и нажмите
обновление. В стандартном макете обновление имитирует успешный результат.
Снимки этой редакции — `design/screenshots/windows-actions/`.

## Граница проверки

В браузере просмотрены три режима, переключение, таймер/свечение,
масштабирование, прокрутка и открытие замечаний. Снимки находятся в
`design/screenshots/windows-layouts/`; визуальный отчёт — `design-qa.md` в корне.
Анализ изменённых Dart-файлов используется только для выявления ошибок кода.

В Windows host добавлен канал `exvpn/window` с командой `setLayout` и
фиксированными именами режимов. Исходники учитывают DPI, рамку, рабочую
область монитора и сохраняют пропорции при растяжении; maximize отключён.
Новый native host включён в локальную Windows-сборку, описанную выше;
проверка всех краёв, DPI и смены монитора ещё не завершена.
Опубликованный релиз 0.1.0 Demo этой редакцией не заменяется.
