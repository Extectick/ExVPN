# Резервирование ключей Android и Shorebird

Локальный инструмент `scripts/release/signing-backup.ps1` работает на Windows
в PowerShell 7.6 / .NET 10. Он не обновляет SDK и не включён в CI: здесь нужны
локальная DPAPI-идентичность и ввод пароля. Отдельные синтетические проверки:

```powershell
pwsh -NoProfile -File scripts/release/test-signing-backup.ps1
```

Экспорт создаёт новый каталог с Android PKCS#12 и зашифрованным PKCS#8
Shorebird. Используются стандартные .NET API, AES-256-CBC и PBKDF2-SHA256
с 600000 итераций; PKCS#12 имеет MAC. Закрытые ключи и пароли не записываются
открытым текстом. Расшифрованные байтовые буферы очищаются; гарантии очистки
всей памяти процесса, включая управляемые строки пароля, нет.

```powershell
# Пароль вводится в локальной консоли; не записывайте его в команду или чат.
pwsh -NoProfile -File scripts/release/signing-backup.ps1 `
  -Mode Export -BackupDirectory V:\GitProjects\ExVPN\.private\signing-backup-01

pwsh -NoProfile -File scripts/release/signing-backup.ps1 `
  -Mode Verify -BackupDirectory V:\GitProjects\ExVPN\.private\signing-backup-01

# Восстановление только в НОВЫЙ каталог: действующие ключи не заменяются.
pwsh -NoProfile -File scripts/release/signing-backup.ps1 `
  -Mode Restore -BackupDirectory V:\GitProjects\ExVPN\.private\signing-backup-01 `
  -RestoreDirectory V:\GitProjects\ExVPN\.private\signing-restored-01
```

Скрипт сверяет сертификат Android побайтно с `config/signing/android-release-cert.pem`
и обе пары ключей — подписью случайного сообщения против доверенных public keys.
APK сохраняет ту же signing identity; alias `exvpn` проверяется отдельным Java
keytool в тесте. Restore создаёт новые DPAPI-файлы для текущего пользователя.
Сертификаты в системное хранилище не устанавливаются. Неверный пароль,
повреждённый файл или другая публичная идентичность останавливают восстановление.

Каталог вывода имеет ACL текущего пользователя и SYSTEM. Существующие файлы,
каталоги и ссылки не перезаписываются. Внутри репозитория выход разрешён только
под `.private/`; вне него можно указать новый каталог с существующим родителем.
При отказе частично созданный каталог не считается проверенной копией.

После успешного экспорта пользователь должен перенести зашифрованный каталог
на отдельный носитель, сохранить пароль отдельно и выполнить Verify/Restore
на другом Windows-профиле с доверенными public keys из проверенного исходника.
Копия на этом же диске не защищает от потери компьютера. Перед использованием
восстановленного Android ключа нужен тест подписи и обновления APK; одно чтение
keystore его не заменяет.
