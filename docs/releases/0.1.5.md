# ExVPN 0.1.5 Preview

- Исправлен запуск Windows-обновления после загрузки пакета.
- На Android добавлены проверка новой версии, загрузка подписанного APK и
  открытие системного установщика. Полоса обновления теперь есть и на мобильном
  экране. Для установки потребуется разрешение Android и подтверждение пользователя.
- Отмена установки сохраняет возможность повторить её. Повреждённый APK
  загружается заново; открытие установщика не выдаётся за успешное обновление.

Из предыдущих версий потребуется один ручной переход на 0.1.5: старый Windows
updater отклоняет запуск помощника, а Android APK updater в них отсутствовал.
Отключите ExVPN/PROXY перед установкой. Подписки и настройки сохраняются.

Это Preview. Android подписан прежним release-ключом. Windows пока без подписи
издателя Authenticode. Полная приёмка защиты и физических устройств продолжается.
Dart OTA в ordinary Flutter-сборках недоступен; native изменения доставляются
полным пакетом. Пользовательские подписки в выпуск не включены.
