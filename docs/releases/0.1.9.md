# 0.1.9+30 — кандидат новой Shorebird-базы

2026-10-20. Публикация разрешена пользователем только после runtime-проверок.
Основной установленный Windows-клиент пока не меняется; испытания выполняются
в Android-эмуляторе и отдельном Windows Sandbox.

В кандидат входят расширенные Xray/Hiddify-профили и служебный primary/backup
из `1d99998`, а также SOCKS5 TCP (с TLS и без), HTTP/HTTPS CONNECT и WireGuard.
WireGuard принимает ограниченные Xray/sing-box JSON и `.conf` с одним peer;
ключи и сетевые адреса проверяются, используется только userspace, DNS и
маршруты ОС провайдера не применяются. TUIC/OpenVPN отсутствуют в закреплённом
ядре и сюда не включены. Shadowsocks 2022 уже был доступен.

SOCKS/HTTP имеют явную пометку TCP и отсутствия TLS для открытых вариантов.
UDP кроме обработки DNS блокируется, включая UDP исключённых приложений:
это консервативное ограничение этих профилей, не разрешение прямого обхода.
Для UDP следует использовать поддерживающий его протокол. WireGuard не
проверяется TCP-ping: готовность устанавливается реальным HTTPS.

Новый native-код требует полного базового APK/EXE. После принятия базы
совместимые Dart/UI-изменения снова выпускаются подписанными патчами.
Новая база не заменяет полную стабильную приёмку E1, физического Android и
подпись Windows издателем. Канал остаётся Preview/beta.

Гейты до публикации:

Первый Windows controller-стенд подтвердил primary→backup и HTTPS IPv4/IPv6,
но выявил потерю прямого доступа исключённых приложений при полном отказе
группы: удалялся TUN. WFP-защита оставалась активной (416 наблюдений без
отказов), защищённый IPv4/IPv6 и свежий DNS блокировались. Это **не пройденная
приёмка**. [Первичный отчёт](../evidence/windows30-failover-initial.json).
Workflow39317376146 отменён до native/build/upload; база в облаке не
регистрировалась, опубликованные APK/EXE/feed не менялись. Требуется исправить
ветку и повторить затронутую runtime-матрицу. Все DNS-запросы сохраняют
VPN-only политику: при полном отказе DNS не получает прямого fallback, даже
для исключённого приложения; проверка его доступности использует числовой IP.
