# ExVPN 0.1.15 Preview

- В настройках появился раздел «Сайты и IP» с режимами «Выключено»,
  «Исключения» и «Только эти».
- Добавлены редактируемые пресеты сервисов и сохранение собственных списков.
- Поддерживаются домены, ссылки HTTP(S), IPv4/IPv6 и подсети CIDR.
- Настройки сохраняются локально; изменения применяются после сохранения
  при отключённом VPN. Простое открытие раздела ничего не включает.

Версия **0.1.15+37**, ревизия интерфейса **11**, Android11+ и Windows x64.
Это новая полная база из-за изменений нативной маршрутизации и ресурсов.
Обычные совместимые изменения Dart/UI по-прежнему доставляются OTA-патчами.

Политика сайтов предназначена для режима VPN/TUN. DNS и соединения с неизвестным
владельцем остаются через VPN. Для Windows PROXY активная политика сайтов
не поддерживается.

Выпуск Preview: системная TUN-приёмка новой политики, физический Android,
новая OTA apply/rollback-проверка, полная E1-приёмка и Windows Authenticode
остаются открытыми. Этот выпуск не объявляется стабильным.
