# ExVPN 0.1.14 Preview

- Расширен импорт WireGuard: ссылки `wg://` и `wireguard://`, конфигурации INI,
  Xray JSON и актуальные WireGuard endpoints sing-box. Поддерживается один peer.
- Добавлен импорт sing-box VMess, Trojan, Shadowsocks и gRPC.
- Улучшена совместимость VLESS с вариантами полей REALITY и TCP без отключения
  проверки сертификатов, ключей или обязательных параметров безопасности.
- Добавлен MASQUE через QUIC/TLS в формате Xray JSON с логином и паролем.

Версия **0.1.14+36**, Android11+ и Windows x64. Это новая полная база ядра;
совместимые изменения интерфейса по-прежнему доставляются подписанными патчами.
TUIC/OpenVPN требуют отдельных движков и в этот выпуск не включены.

WireGuard проверен через настоящий Android TUN: HTTPS IPv4/IPv6, DNS A/AAAA,
три отказа/восстановления сервера. Windows TUN подтвердил HTTPS IPv4, DNS,
три таких же цикла с постоянной блокировкой прямого трафика и восстановлением
исходных маршрутов/DNS. В Windows Sandbox нет внешнего IPv6; его приёмка остаётся
открытой. MASQUE прошёл повторные core-тесты QUIC/TLS, IPv4/IPv6, DNS и отказов,
но его платформенная TUN-проверка ещё не выполнена.

Выпуск Preview: полная приёмка защиты E1 и подпись Windows Authenticode остаются
открытыми. Физический Android и OTA apply/rollback этой новой базы также не
проверены. Конкретные результаты записаны в чек-листе проекта; Preview не является
стабильной версией с завершённой приёмкой защиты.
