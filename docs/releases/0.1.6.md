# ExVPN 0.1.6 Preview

- В минимальном режиме настройки, выбор сервера и добавление подписки занимают
  всю область окна. Форма импорта стала компактнее.
- Название подписки расположено над вкладками и заполняется из данных провайдера.
  Ссылка HTTPS подставляется из буфера обмена; ручное название сохраняется.
- Поддерживаемые подключения обновляются, неподдерживаемые записи пропускаются
  без предупреждений. Ошибка загрузки отмечается значком у нужной подписки;
  прежний рабочий список сохраняется при повреждённых данных или ошибке сети.
- QR-импорт объединён в иконку изображения: выбор файла или локального пути
  PNG/JPEG из текстового буфера. Камера в Android/Windows пока недоступна.

Обновление опубликовано в существующий предварительный канал. Android подписан
прежним ключом; установка потребует подтверждения системы. Windows пока без
подписи издателя Authenticode. Это Preview, полная приёмка защиты продолжается.
Пользовательские подписки и ключи в пакет не включены.
