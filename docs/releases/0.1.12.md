# ExVPN 0.1.12 Preview

- Проверка обновлений при возвращении в приложение и разворачивании окна Windows.
  Повторные события объединяются, текущая загрузка и готовый пакет сохраняются.
- Android загружает APK отдельным системным фоновым заданием. Частичный файл
  сохраняется; после восстановления сети загрузка продолжается с имеющегося места,
  если сервер поддерживает докачку. После открытия приложения отображается её статус.
- Исправлено ожидание разрешения VPN на Android: системный запрос запускается из
  активного окна, возврат фокуса сам по себе больше не считается отказом.
  Принять системный запрос должен пользователь.
- Включены подготовленные изменения списка подписок: редактирование, автопинг
  видимых серверов и неактивное отображение неподдерживаемых подключений.

Это новая полная база **0.1.12+34** для Windows x64 и Android 11+.
Фоновая докачка и исправленный запрос разрешения становятся доступны после её
установки. Следующие совместимые изменения интерфейса остаются OTA-патчами.

По запросу пользователя автоматические тесты и проверки на устройствах для этого
выпуска не запускались; приёмку выполняет пользователь. Сборка и подпись пакета не
подтверждают исправление на конкретном телефоне. Ограничения фоновых заданий и
принудительная остановка приложения управляются Android. Установка APK требует
системного подтверждения.

Выпуск остаётся Preview: Windows без Authenticode; физический Android и полная
матрица защиты E1 не приняты. Политика TUN/DNS/исключений и отсутствие прямого
fallback не менялись.
