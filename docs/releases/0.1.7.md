# ExVPN 0.1.7 Preview

**Не опубликована.** Попытка CI39239871468 остановилась на подготовке SDK
до сборки APK/EXE и регистрации в Shorebird. Тег исходников сохранён;
базовый выпуск продолжен как 0.1.8+29. Ниже — исходный план версии.

- Добавлены подписанные небольшие обновления интерфейса через Shorebird для
  Android и Windows. Для перехода с прежних версий нужен этот полный пакет один раз.
- Исправления совместимой Dart-логики и дизайна загружаются отдельно от APK/EXE.
  На Android они применяются при следующем полном запуске приложения;
  Windows может перезапустить интерфейс, сохранив работающую VPN-службу.
- При повреждении патча проверка подписи не позволяет его загрузить.
  Поддерживается возврат к исходному интерфейсу базового выпуска.
- Нативное VPN-ядро, драйверы, разрешения и встроенные ресурсы по-прежнему
  обновляются полным пакетом.

Android сохраняет прежний ключ подписи. Windows пока без подписи издателя
Authenticode. Выпуск остаётся Preview; общая приёмка VPN и физического Android
ещё продолжается. Пользовательские подписки и ключи в пакет не включены.
