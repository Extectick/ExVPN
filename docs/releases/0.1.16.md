# ExVPN 0.1.16 Preview

- Исправлена маршрутизация сайтов со скрытым TLS-именем (ECH): такое имя
  больше не разрешает прямое соединение в режиме «Только эти».
- Сохранены явные правила IP/подсетей, проверка владельца соединения
  и защищённая маршрутизация DNS.
- Правила доменов и IP проверены через TUN в Android-эмуляторе и Windows Sandbox,
  включая отказ VPN-сервера и IPv6 в пределах возможностей стендов.

Версия **0.1.16+38**, ревизия интерфейса **11**, ядро **26.10.10-exvpn.6**.
Android11+ и Windows x64. Это новая полная база из-за исправления нативного ядра.
Совместимые изменения Dart/UI по-прежнему могут доставляться OTA-патчами.

Выпуск Preview. Физический Android, Windows installed SCM/DPAPI roundtrip,
прямой IPv6 на Windows, новая OTA apply/rollback-проверка, полная E1-приёмка
и Windows Authenticode остаются открытыми. Стабильная готовность не заявляется.
