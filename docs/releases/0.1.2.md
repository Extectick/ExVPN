# ExVPN 0.1.2 Preview

Обновление Android и Windows: более компактные настройки, три режима выбора
приложений, иконки приложений и возможность изменить сервер или режим во время
подключения. Для Discord в Windows сохраняется выбор после обновления программы.

- «Выключено»: весь трафик проходит через VPN.
- «Кроме выбранных»: выбранные приложения работают напрямую.
- «Только выбранные»: выбранные приложения используют VPN; остальные приложения
  с подтверждённым владельцем соединения работают напрямую.
- Поиск закреплён над списком; снять весь выбор можно кнопкой рядом с поиском
  после подтверждения.
- Выбор приложений действует в режиме VPN. Системный PROXY Windows работает
  только для программ, использующих системные настройки прокси.

Чтобы установить обновление, отключите VPN/PROXY и закройте ExVPN. Подписки
и настройки сохраняются. На Android используйте APK для обновления установленной
ExVPN; для Windows — установщик. Системный запрос разрешения установки покажет
Windows. Новым установкам Windows всё ещё требуется явное разрешение сетевого
режима в установщике.

Это предварительный выпуск. APK подписан прежним release-ключом. Windows пока
без подписи издателя Authenticode; Windows может показать предупреждение.
Полная проверка защиты на всех устройствах и протоколах ещё продолжается.
Не считайте этот выпуск подтверждением полной защиты при любой аварии.
На Android строгая системная блокировка включается отдельно в настройках ОС.

Полные Windows-обновления доставляются через проверяемый подписанный канал beta.
Полоса обновления скачивает пакет и предлагает закрытие/перезапуск, когда
подключение отключено. Dart OTA для этих обычных Flutter-сборок недоступен.

Выпуск не содержит подписок. Добавьте свою в приложении. Файлы уведомлений
компонентов, соответствующие исходники Xray и неполный SBOM приложены отдельно.
