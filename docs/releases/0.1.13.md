# ExVPN 0.1.13 Preview

- Если Android не показывает запрос VPN, приложение объяснит, как отключить
  другой постоянный VPN и повторить подключение. Возврат из настроек сам VPN
  не включает.
- Уведомления запрашиваются отдельно от VPN. В настройках ExVPN можно посмотреть
  их состояние и открыть нужный системный раздел.
- Уведомление о подключении содержит кнопку «Отключить»; открывать приложение
  для отключения не требуется. Закрытие интерфейса не останавливает VPN-службу.
- Исправлена проверка полной новой версии при запуске, если ранее был обнаружен
  подготовленный патч интерфейса.

Версия **0.1.13+35** для Windows x64 и Android11+. Изменения Android требуют
установки новой полной версии; последующие совместимые изменения интерфейса
могут доставляться подписанными OTA-патчами.

Выпуск Preview. На Android16 в эмуляторе проверены запрос разрешения, уведомление,
HTTPS/DNS после закрытия интерфейса и отключение из шторки. Приёмку на своём
устройстве выполняет пользователь. HyperOS «Закрыть всё» отдельно не проверялось;
принудительную остановку в настройках Android обойти нельзя.
Windows пока без подписи Authenticode; полная приёмка защиты E1 остаётся открытой.
