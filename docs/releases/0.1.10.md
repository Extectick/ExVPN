# ExVPN 0.1.10 Preview

Новая базовая версия для Windows x64 и Android 11+. Она включает текущий
интерфейс приложения, компактное отображение загрузки обновления, настройки
Kill Switch и просмотр последних событий соединения.

## Обновления

- Доставка обновлений интерфейса переведена на собственный подписанный каталог
  ExVPN в GitHub Releases. Аккаунт и API Shorebird Cloud для этого не нужны.
- Совместимые изменения Dart/UI выпускаются небольшими подписанными патчами
  без повторной сборки APK, установщика, Android-службы и Windows-службы.
- Каталог проверяется по Ed25519, восстановленный код — по RSA4096. Проверяются
  версия базы, движок, платформа, хеши и отменённые патчи.
- Native-код, ресурсы, плагины и зависимости обновляются обычным установщиком.
  Первое обновление до этой базы также требует APK/EXE.
- Неизменённое VPN-ядро повторно используется только после проверки содержимого
  кэша. Сборщик и необходимые входные файлы патчей закреплены в репозитории.

Независима доставка от облачного сервиса. Закреплённый Flutter/Dart runtime
Shorebird остаётся зависимостью сборки; полной независимости от этого toolchain
данный выпуск не обещает.

## Статус

Это Preview, не стабильный выпуск. Windows-установщик пока без Authenticode.
Приёмка на физическом Android-устройстве, полная матрица E1 и отдельный сценарий
native IPv6 underlay остаются открытыми. Существующие требования защиты VPN
не ослаблены для выпуска.
