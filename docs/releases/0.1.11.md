# ExVPN 0.1.11 Preview

Исправление автоматического перезапуска после обновления интерфейса для
Windows x64 и Android 11+. При загрузке совместимого подписанного патча
приложение сохраняет данные и запускается заново с новым кодом. Полученный
отзыв патча также подготавливает возврат и перезапуск.

На Windows меняется только процесс интерфейса; VPN-служба продолжает работать.
На Android обновление ждёт отключения VPN и возвращения приложения на экран,
чтобы не завершить работающий туннель вместе с интерфейсом. Установка полного
APK по-прежнему требует системного подтверждения Android.

Это новая полная база: в Android добавлен закрытый компонент холодного
перезапуска. Следующие совместимые изменения Dart/UI выпускаются подписанными
OTA-патчами без нового APK/EXE. Меню редактирования подписок и новый автопинг
готовятся отдельным следующим патчем.

Подписанный патч и его отзыв проверены в Windows Sandbox и Android-эмуляторе:
приложения сами сменили процессы и прошли UI 4→5→4 с сохранением данных.
Служба Windows не прерывалась; ручные перезапуски и правки кэша не использовались.
[Доказательства](../evidence/independent33-auto-restart.json). Доставка
остаётся через собственный подписанный каталог ExVPN; pinned Flutter/Dart
runtime Shorebird остаётся зависимостью сборки. CDN может задерживать каталог.

Выпуск остаётся Preview: Windows пока без Authenticode; физическое Android-
устройство, полная матрица E1 и отдельный native IPv6 underlay не приняты.
Требования защиты VPN не ослаблены.
