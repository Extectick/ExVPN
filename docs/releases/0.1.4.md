# ExVPN 0.1.4 Preview

Исправления Android и Windows:

- Подключения показаны внутри подписки с тонкими короткими ветками и небольшим
  отступом. Группы сворачиваются.
- Ошибка обновления отмечается у соответствующей подписки. Лишняя полоса с
  кнопкой повтора убрана; последний рабочий список сохраняется.
- При неудачном подключении большая кнопка подсвечивается красным. Защита не
  выключается автоматически; можно явно отключить соединение или сменить сервер.
- Название подписки вводить необязательно: используется имя провайдера, если
  оно есть. Ручные названия сохраняются.
- На Android исправлены системный запрос VPN и значок белки, включая адаптивную
  иконку. Отказ в разрешении можно повторить следующим нажатием подключения.
- Нижние окна можно закрыть потягиванием вниз за содержимое. Длинный список
  сначала прокручивается к началу.

Для обновления отключите VPN/PROXY и закройте ExVPN. Подписки и настройки
сохраняются. После этой версии возвращаться на 0.1.3 и ниже не рекомендуется:
старые версии не читают новый формат сохранённых имён подписок.

Это предварительный выпуск. Android APK подписан прежним release-ключом.
Windows пока без Authenticode; системное предупреждение возможно. Полная
проверка защиты, всех протоколов и физических устройств продолжается.
На Android Always-on VPN и блокировка без VPN включаются отдельно в ОС.
Полные Windows-обновления используют подписанный канал beta; Dart OTA в обычной
Flutter-сборке недоступен. Подписки в выпуск не включены.
