# ExVPN 0.1.0 Demo

Предварительный выпуск для тестирования. Версия приложения **0.1.0+18**.

- **Android 11+**, arm64 и x86_64: `ExVPN-0.1.0-demo-android.apk`.
- **Windows 10/11 x64**: `ExVPN-0.1.0-demo-windows-x64.exe`.

Приложение запускается с пустым списком: добавьте свою совместимую подписку
кнопкой «+», выберите сервер и подключитесь. Включены импорт подписок,
сворачиваемые группы, поиск исключений приложений, темы и реальный VPN backend.
Демо-профили и личные тестовые подписки в пакет не входят.

## Установка

Android APK подписан постоянным release-ключом ExVPN. После загрузки разрешите
установку APK выбранному браузеру/файловому менеджеру и подтвердите системный
запрос VPN. Обновление поверх подписанных сборок +16/+17 использует тот же ключ.
Debug-сборки имеют другую подпись: сначала сохраните подписки, затем удалите
debug-приложение. Физические Android-устройства ещё не прошли полную приёмку.

Windows-установщик не имеет подписи издателя Authenticode; Windows может
показать предупреждение о неизвестном издателе. Для этой demo используйте
тестовую машину или Windows Sandbox. Закройте ExVPN перед установкой/обновлением.
В установщике явно включите **Allow VPN network testing on this controlled
machine**, чтобы разрешить подключение. Эта опция не включается автоматически.
Запускайте установленный клиент из меню «Пуск» под обычной учётной записью.
Удаление — через «Установленные приложения»; заранее отключите VPN и закройте UI.

## Ограничения

Это не стабильный выпуск и не подтверждение полной защиты от утечек.
Полная матрица IPv6/DNS, аварий, смены сети, sleep/resume и исключений ещё
не пройдена. На Android полный системный lockdown настраивается пользователем
через Always-on VPN / Block connections without VPN; интерфейс не отключает его
самостоятельно. Протокол или вариант транспорта конкретного провайдера может
не поддерживаться либо требовать дополнительной проверки.

Эта demo собрана обычным Flutter. **Dart OTA/Shorebird в ней недоступен**;
обновление приложения выполняется новым APK/установщиком. Релиз не содержит
готовых платных подписок, регистрации или оплаты.

В assets приложены SHA-256, build metadata, отчёты аудита, уведомления о
лицензиях и точные соответствующие исходники изменённого Xray внутри notices ZIP.
SBOM явно помечен `incomplete`: он не выдаётся за полный граф итоговой линковки.
`releaseReady=false` в аудите сохранён; критерии стабильного выпуска не закрыты.

Исходники и этапы: [ExVPN](https://github.com/Extectick/ExVPN),
[чек-лист](https://github.com/Extectick/ExVPN/blob/main/docs/CHECKLIST.md).
