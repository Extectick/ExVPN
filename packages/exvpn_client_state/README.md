# ExVPN client state

Чистый Dart-пакет для состояния главного экрана. Он не зависит от Flutter, не
открывает сеть и не меняет состояние VPN или системной защиты.

`AppController()` начинает с пустого списка. `AppController.demo()` явно создаёт
две группы из шести синтетических серверов для визуального стенда. Все демонстрационные
серверы используют домен `.invalid`, не имеют рабочих credentials и помечены
`isDemo`; задержки в них — образцы дизайна, а не измерения. UI обязан обозначить
этот режим как DEMO. В обычном импорте задержки отсутствуют.

## Контракт интерфейса

- `groups`: неизменяемые `SubscriptionGroup` с `id`, `name`, `servers`, `expanded`,
  `issues`, `isDemo`, `sourceUrl`, `updatedAt`.
- `selectedServer`, `selectedGroupId`, `selectedServerId`: выбор узла, включая
  различие одинаковых профилей в разных подписках.
- `showAddSubscriptionButton`: `true` только при полном отсутствии подписок.
  Пустая или ошибочная существующая группа остаётся группой с диагностикой.
- `changes`: broadcast `Stream<void>`; уведомление приходит после изменения
  состояния. UI читает актуальные getters и отписывается при уничтожении.
- `addSubscription(name: ..., raw: ..., sourceUrl: ...)`, `updateSubscription(groupId: ..., raw: ..., sourceUrl: ..., clearSourceUrl: ...)`:
  строгий парсер доменного пакета, результат `SubscriptionImportResult`.
- `toggleGroup(id)`, `selectServer(groupId: ..., serverId: ...)`,
  `removeSubscription(id)`, `dispose()`.

Сворачивание сохраняет выбор. Удаление выбранной подписки выбирает первый
доступный узел оставшихся групп. При успешном обновлении сохраняется стабильный
ID выбранного сервера; исчезнувший сервер заменяется первым узлом той же группы.
Ошибочная/частичная замена не стирает рабочий список. В новом или пустом списке
поддерживаемые узлы частичного импорта доступны вместе со всеми кодами проблем.

`ServerEntry` предоставляет `profile`, `id`, `name`, `countryCode`, `protocolLabel`,
`latencyMs`, `isDemo`. Страна реального импорта извлекается только из явного флага
в начале имени; геолокация и догадки по hostname не выполняются. Поля профиля
содержат секреты, поэтому их нельзя логировать или включать в скриншоты тестов.
`toString` моделей скрывает пользовательские данные. Ошибки импорта содержат
только безопасные коды и индексы.

## Границы текущей реализации

Импорт принимает содержимое подписки (URI/список/Base64/Xray JSON), но не скачивает
HTTPS URL. Сам пакет хранит нормализованные профили в памяти; исходная строка
не сохраняется. `exportSnapshot()` и `AppController.fromSnapshot(...)` дают
ограниченный версионированный снимок для защищённого хранилища приложения.
Снимок содержит секреты: JSON нельзя писать в обычный файл или журнал.
DEMO-группы исключаются. Сохраняются выбор, раскрытие групп, безопасные коды
ошибок, HTTPS-источник и время последнего применённого обновления.
Ошибочная замена не меняет источник/дату. Ручная успешная замена с
`clearSourceUrl: true` удаляет URL. Сеть, шифрование и системный мост реализуются
вне этого пакета. Здесь нет фальшивого `connected` или `protected` состояния.
