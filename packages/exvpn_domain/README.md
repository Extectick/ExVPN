# exvpn_domain

Чистая Dart-библиотека ExVPN: типизированные профили и `VpnBridge`, ограниченный парсер подписок и неизменяемый снимок обновления. Она не открывает сетевых соединений, не запускает VPN и не сохраняет credentials на диск.

## Проверка

Из корня репозитория в PowerShell:

```powershell
. ./scripts/bootstrap/enter-environment.ps1
Push-Location packages/exvpn_domain
dart pub get --enforce-lockfile
dart analyze
dart test
Pop-Location
```

SDK закреплён в `scripts/bootstrap/toolchain.lock.json`, package versions/checksums — в `pubspec.lock`.

## Импорт

`SubscriptionParser.parse` принимает обычный текст, Base64-список URI и Xray JSON с `outbounds`. Поддерживаются VLESS, VMess JSON URI, Trojan, Shadowsocks SIP002/legacy и Hysteria2. JSON извлекает поддерживаемый единственный сервер/пользователя из outbound; другие варианты явно возвращают проблему импорта.

Локальные поля корня Xray JSON не исполняются и не передаются ядру; возвращается `ignoredLocalConfiguration`. Неизвестные параметры, неоднозначные дубликаты JSON/query, небезопасный TLS и неиспользуемые настройки транспорта отклоняются. Максимум по умолчанию: 2 MiB UTF-8, 5000 записей и 64 уровня вложенности JSON.

`ConnectionProfile.toString()` скрывает поля. `toNativeJson()` **содержит секреты**: его результат предназначен только для защищённого хранилища или аутентифицированного локального native bridge. Ошибки импорта содержат индекс и безопасный код, а не исходный текст.

## Обновление снимка

`SubscriptionSnapshot.apply(result, startedAt)` получает время **начала** попытки. Вызывающий код должен захватить его до сетевого запроса, объединять параллельные обновления одной подписки и применять ответ к актуальному снимку. Ответ более старой попытки не заменяет новую. При изменении системного времени оркестратор должен сбросить/переинициализировать порядок попыток; timestamps не заменяют монотонный сетевой request ID.

Ошибка, пустой ответ или частично повреждённое обновление сохраняют существующий рабочий список и последнюю успешную дату. Первый частичный импорт может показать корректные записи вместе с причинами отказа остальных. Уведомление об отброшенной локальной конфигурации провайдера не мешает обновлению проверенных профилей.

Хранилище, загрузчик HTTPS, QR, платформенные реализации `VpnBridge` и фактическая работоспособность туннелей находятся за пределами этого пакета. Успешный разбор профиля не подтверждает соединение или принятие конфигурации ядром.
