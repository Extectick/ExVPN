# Визуальное направление ExVPN

Дата: 2026-10-16. `concepts/` содержит макеты. Исходники работающего Flutter UI находятся в `apps/exvpn`; визуальная приёмка фиксируется отдельно от изображений-концепций.

## Текущий выбор и реализация

Последнее поручение пользователя: «Этот вариант мне больше нравится, только текст ближе надо к белке. Выполняй дизайн, реализовывай». Выбран приложенный вариант с **маленькой контурной белкой**, не предыдущий увеличенный логотип. [Эталон с близким текстом](concepts/approved-close-wordmark.png) сохраняет белку слева и белую надпись ExVPN с малым зазором и общей нижней линией.

По прямому поручению реализован Flutter UI в `apps/exvpn` параллельно незавершённому техническому этапу E1. Есть сворачиваемые подписки, выбор узла, импорт HTTPS/текста, ручное обновление, удаление и светлая тема. Обычный запуск пустой; синтетические серверы включаются явно через `?demo=1` / `EXVPN_DEMO=true`. Настоящий туннель пока не запускается, постоянное защищённое хранилище и системная защита не подключены. Кнопка сообщает об отсутствии VPN-модуля, не имитируя успешное подключение.

Ниже сохранена история поиска. Более ранние изменения размера не заменяют последний выбранный пользователем эталон.

## Зафиксированные изменения

- Сохранить белку как символ, графитовую основу, большую круглую кнопку и
  янтарное выделение выбранного сервера.
- В заголовке списка справа находится кнопка-иконка «+» для добавления подписки.
- Кнопка обновления находится непосредственно слева от «+» в том же заголовке.
- Каждая подписка образует отдельную сворачиваемую группу. Заголовок содержит
  стрелку, название и количество подключений; нажатие сворачивает или раскрывает список.
- В макете основная подписка раскрыта (4 подключения), резервная свёрнута (2 подключения).
- Строка: флаг, название и протокол под ним, задержка, отметка выбранного сервера.
- Между флагом и названием нет точки/индикатора.
- Большая кнопка «Добавить подписку» показывается **только когда подписок нет**.
  Наличие подписки с пустым или ошибочным списком серверов не считается отсутствием подписок.
- Сворачивание группы не меняет выбранный сервер и активное подключение.

## Токены текущей реализации

| Элемент | Значение в исходниках |
|---|---|
| Основной фон | Graphite `#141617` |
| Янтарный акцент | `#FFBD51` |
| Основной текст тёмной темы | `#F7F6F3` |
| Вторичный текст | `#A0A3A7` |
| Светлая поверхность | `#F6F5F1` |
| Шрифт | Bundled Inter, лицензия OFL 1.1 |
| Белка / надпись | Маска 40×40 logical px, видимый контур около 26 px; текст сдвинут на 3 px к белке; ExVPN 20 px, weight 500 |
| Компоновка | Одна колонка на узком экране; две колонки от 900 logical px; предел содержимого 1180 px |

Это параметры исходников на момент записи, а не доказательство визуального совпадения. Итоговые размеры сверяются по работающему UI и зафиксированному эталону.

## Проверка и оставшиеся состояния

Проверены 15 widget-тестов групп/выбора/пустого состояния/импорта/удаления/тем, 35 тестов загрузчика и 7 тестов кнопки. Всего 57 тестов; `flutter analyze` без замечаний, release web-сборка выполнена. Полная визуальная сверка ещё выполняется; платформенная приёмка не отмечена завершённой.

Уточнение 2026-10-16: по просьбе пользователя возвращены мягкое янтарное свечение и расходящаяся затухающая волна при нажатии. Свечение появляется при наведении, фокусе и нажатии, волна длится 640 мс; эффект рисуется за границами кнопки без `ClipOval`. Системное отключение анимации соблюдается. Тесты проверяют фактические пиксели за четырьмя краями, затухание и однократное действие. В браузере проверена вся окружность: [главный экран со свечением](screenshots/mobile-glow.png), [кнопка крупнее](screenshots/power-glow.png). Источник — снимок работающей release web-сборки `review-glow-full.jpg`; это визуальная обратная связь кнопки, не подтверждение VPN-подключения.

В работе остаются разрешения Android, реальные переходы подключения/восстановления/блокировки, фактическая системная защита и проверка Windows/физического Android. Разрешение реализовать UI до E1 не закрывает эти требования. Браузерные снимки и widget-тесты не заменяют платформенные испытания.
